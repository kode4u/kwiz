# Reference Guide: MCQ Classification & Cognitive Levels in CS Education

This reference document outlines the **MCQ classification framework** used to evaluate the pedagogical quality of questions generated by the **L3M-RAG** system. It maps each question category to its target cognitive level under **Bloom's Revised Taxonomy**.

---

## 📚 1. Theory & Concepts
*   **Target Bloom's Cognitive Levels:** *Remembering* (Retrieve relevant knowledge) & *Understanding* (Construct meaning).
*   **Focus:** Core computer science principles, definitions, terminology, and conceptual relationships (e.g., OOP, DBMS rules, Big-O definitions) without requiring code tracing.

### 📝 Example Question
*   **Topic:** Object-Oriented Programming (Java)
*   **Question Stem:** 
    > Which OOP concept restricts direct access to an object's state and forces all interaction to occur through a well-defined public interface?
*   **Options:**
    *   `[ ]` A) Inheritance
    *   `[ ]` B) Polymorphism
    *   `[x]` C) Encapsulation *(Correct Key)*
    *   `[ ]` D) Abstraction
*   **Rationale:** Encapsulation hides private fields (data hiding) and exposes access via public getter/setter methods.

---

## 🔍 2. Syntax & Code Reading
*   **Target Bloom's Cognitive Levels:** *Remembering* (Recall programming syntax rules) & *Analyzing* (Distinguish structures/deconstruct code patterns).
*   **Focus:** Identifying syntax violations, compiling errors, code structural anomalies, block scope rules, or declaration faults in code snippets.

### 📝 Example Question
*   **Topic:** Python Syntax & Structure
*   **Question Stem:**
    > Consider the following Python code snippet:
    > ```python
    > def calculate_sum(a, b):
    > result = a + b
    >     return result
    > ```
    > What error will occur when executing this script?
*   **Options:**
    *   `[ ]` A) SyntaxError (Missing semicolon)
    *   `[x]` B) IndentationError (Inconsistent spacing inside the function block) *(Correct Key)*
    *   `[ ]` C) TypeError (Function arguments lack type declarations)
    *   `[ ]` D) NameError (The variable 'result' is undefined)
*   **Rationale:** Python relies on whitespace indentation for code blocks. Line 2 has zero indentation, throwing an `IndentationError`.

---

## ⚙️ 3. Code Tracing & Output Calculation
*   **Target Bloom's Cognitive Levels:** *Applying* (Execute code logic) & *Analyzing* (Trace variables through operations).
*   **Focus:** Running variable value tracking, execution trace lines, and loop/conditional output calculations over a given code block.

### 📝 Example Question
*   **Topic:** Loop & Conditional Execution (Java)
*   **Question Stem:**
    > What is the printed output of the following Java code segment?
    > ```java
    > int sum = 0;
    > for (int i = 1; i <= 5; i++) {
    >     if (i % 2 == 0) {
    >         sum += i * 2;
    >     } else {
    >         sum += i;
    >     }
    > }
    > System.out.println(sum);
    > ```
*   **Options:**
    *   `[ ]` A) 15
    *   `[ ]` B) 18
    *   `[x]` C) 21 *(Correct Key)*
    *   `[ ]` D) 25
*   **Trace Steps:**
    *   `i = 1` (Odd): `sum += 1` $\rightarrow$ `sum = 1`
    *   `i = 2` (Even): `sum += 2 * 2 = 4` $\rightarrow$ `sum = 5`
    *   `i = 3` (Odd): `sum += 3` $\rightarrow$ `sum = 8`
    *   `i = 4` (Even): `sum += 4 * 2 = 8` $\rightarrow$ `sum = 16`
    *   `i = 5` (Odd): `sum += 5` $\rightarrow$ `sum = 21`
