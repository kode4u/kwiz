Verifying Python Installation
Verification Steps

Installing Python Packages
Python Packages
Python's ecosystem thrives on packages from PyPI (Python 
Package Index) that extend its functionality.
Key Point: Always install packages into your virtual 
environment to isolate project dependencies.
Installing Packages: Step-by-Step
1 Modify your script to use the desired package:
# hello.py
import numpy as np
msg = "Roll a dice!"
print(msg)
print(np.random.randint(1,9))
2 Open integrated terminalin VS Code:
Terminal → Create New Terminal
3 Install the package using pip:
>_ pip install numpy
4 Verify installation by running your script:
>_ python hello.py

Managing Dependencies
Recording Dependencies
Python projects rely on external packages from PyPI. It's 
important to record these dependencies to ensure consistent 
consistent environments across machines.
• Use pip freeze to list all installed packages
• Redirect output to requirements.txt
• Commit this file to version control
Best Practice: Update requirements.txt regularly as you install 
new packages.
Creating requirements.txt
# Create requirements.txt file
pip freeze > requirements.txt
# Contents of requirements.txt
numpy==1.21.0
pandas==1.3.0
matplotlib==3.4.2
Installing from requirements.txt
# Install all dependencies
pip install -r requirements.txt
